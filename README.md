# Webchanges – AI Connector (MCP)

Connect WordPress to any MCP-compatible AI client so agents can manage content, blocks, media, SEO, forms, and site settings over the Model Context Protocol.

This is the **WordPress.org (Lite) edition** — the guideline-compliant subset (no arbitrary code / filesystem execution, no self-updater, no telemetry). The full agency build lives in a separate repository.

- Requires WordPress 6.9 or newer — the Abilities API ships in core from 6.9.
- Requires PHP 8.0+.
