# Webchanges – AI Connector (MCP)

Connect WordPress to any MCP-compatible AI client so agents can manage content, blocks, media, SEO, forms, and site settings over the Model Context Protocol.

This is the **WordPress.org (Lite) edition** — the guideline-compliant subset (no arbitrary code / filesystem execution, no self-updater, opt-in telemetry off by default). The full agency build lives in a separate repository.

- Requires WordPress 6.9+ (Abilities API in core) or the standalone "Abilities API" plugin.
- Requires PHP 8.0+.
